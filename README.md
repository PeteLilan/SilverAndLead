CS 4700 Spring 2026 project for Dr. Jamshidi by Neil Patel and Jacob Carasco

WASD is for standard controls
Shift is to sprint
Left mouse button to shoot
The objective of the game is to kill monsters, and get a high score, it's very much an arcade-style game
Feature implemented
  -Arena map
  -Player movement options
  -Shooting mechanics
  -Enemies that track player position
  -A working score system
  -Sound Effects
  -2 different enemy types
Enemies
  -Red slime - short red slime that takes 4 shots to kill, gives 100 points upon death
  -Dark slime - short and stout darkly colored slime that takes 10 shots to kill, but gives 250 points upon death
